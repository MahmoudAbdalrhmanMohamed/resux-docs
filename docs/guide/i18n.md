# i18n & Localization

Resux features built-in internationalization (i18n) support through the `resux:i18n` module. It allows you to build multi-language resumable apps with dynamic locale switching, LTR/RTL text direction handling, localized route generation, and automatic SEO metadata (`hreflang` alternate links).

## Enabling the i18n Module

To enable i18n in your Resux application, register `resux:i18n` in your `resux.config.ts`:

```ts
import { defineResuxConfig } from 'resuxjs'

export default defineResuxConfig({
  modules: [
    ['resux:i18n', {
      defaultLocale: 'en',
      fallbackLocale: 'en',
      strategy: 'prefix_except_default',
      locales: [
        { code: 'en', name: 'English', dir: 'ltr' },
        { code: 'ar', name: 'Arabic', dir: 'rtl' }
      ],
      messages: {
        en: './i18n/locales/en.json',
        ar: './i18n/locales/ar.json'
      },
      seo: {
        hreflang: true
      }
    }]
  ]
})
```

## Configuration Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultLocale` | `string` | **Required** | The primary default locale code for your app (e.g. `'en'`). |
| `fallbackLocale` | `string` | `defaultLocale` | Locale used when a key missing in active locale. |
| `strategy` | `'prefix_except_default' \| 'prefix' \| 'no_prefix'` | `'prefix_except_default'` | Routing prefix strategy. |
| `locales` | `ResuxI18nLocaleInput[]` | `[]` | List of supported locale objects with `code`, `name`, and optional `dir` (`'ltr'` or `'rtl'`). |
| `messages` | `Record<string, string \| Record<string, unknown>>` | `{}` | Message catalog sources per locale (JSON file relative paths or inline dictionaries). |
| `seo.hreflang` | `boolean` | `true` | Automatically inject canonical and alternate `hreflang` tags into `<head>`. |

## Routing Strategies

Resux supports three routing strategies for localized URL prefixes:

1. **`prefix_except_default`** (Default): Default locale routes have no prefix (e.g., `/about`), while non-default locales are prefixed (e.g., `/ar/about`).
2. **`prefix`**: All routes are prefixed with the locale code (e.g., `/en/about`, `/ar/about`).
3. **`no_prefix`**: Routes retain standard paths without URL prefixes; language state is managed in-app or via headers/cookies.

## `useI18n()` Composable

The `useI18n()` composable provides complete reactive access to the current locale state and translation functions in your SFCs.

```vue
<script setup>
const { locale, dir, locales, t, setLocale, switchLocalePath } = useI18n()
</script>

<template>
  <div :dir="dir">
    <h1>{{ t('welcome.title', { name: 'User' }) }}</h1>
    <button @click="setLocale('ar')">Switch to Arabic</button>
  </div>
</template>
```

### Composable Properties & Methods

- **`locale`** (`Ref<string>`): Computed ref for the current active locale code.
- **`dir`** (`Ref<'ltr' | 'rtl'>`): Computed ref for current text direction based on active locale configuration.
- **`locales`** (`ResuxI18nLocale[]`): Array of configured locale objects.
- **`t(key: string, params?: Record<string, unknown>): string`**: Translates a dot-notated key with optional interpolation variables (`{key}`).
- **`tm(key: string): unknown`**: Returns raw message object or subtree for nested lookup.
- **`resolveLocalized(value: unknown): string | null`**: Utility to resolve localized strings from objects (e.g. `{ en: 'Hello', ar: 'مرحبا' }`).
- **`localePath(to: string, localeCode?: string): string`**: Formats a local path according to active routing strategy and target locale.
- **`switchLocalePath(localeCode: string, to?: string): string`**: Returns the target path for switching the active locale.
- **`setLocale(localeCode: string, to?: string): Promise<void> | void`**: Switches the active locale and updates route navigation.

## Template Globals

Resux automatically exposes i18n helpers in template setup context:

- **`$t(key, params?)`**: Direct translation call inside template bindings.
- **`$tm(key)`**: Direct raw message accessor inside templates.

Example:

```vue
<template>
  <nav>
    <a :href="localePath('/cart')">{{ $t('nav.cart') }}</a>
    <a :href="switchLocalePath('ar')">عربي</a>
  </nav>
</template>
```

## SEO & Direction (LTR/RTL)

When `seo.hreflang` is enabled, Resux automatically manages `<head>` elements:

- Sets `<html lang="...">` and `<html dir="...">` dynamically during SSR rendering.
- Injects canonical and alternate `<link rel="alternate" hreflang="...">` tags for search engine indexing across languages.

```html
<!-- Automatically generated in HTML document head -->
<html lang="ar" dir="rtl">
<head>
  <link rel="alternate" hreflang="en" href="https://example.com/about">
  <link rel="alternate" hreflang="ar" href="https://example.com/ar/about">
</head>
```
